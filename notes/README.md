# Deep Learning Study Notes

This directory contains my handwritten study notes, neural network architecture sketches, and mathematical derivations created while studying Deep Learning.

Keeping handwritten notes alongside notebook experiments helps me understand gradient flow, backpropagation calculus, and layer design decisions.

## Planned Structure

As I digitize and upload scans/photos of my notebook pages, they will be organized into the following topics:

- `01-neural-network-foundations/`: Perceptron mechanics, activation functions (ReLU, Sigmoid, Softmax), forward propagation, loss functions (binary & categorical cross-entropy), and SGD optimization with momentum.
- `02-computer-vision-cnn/`: Convolution operation mathematics, kernel filters, stride and padding, pooling operations (Max Pooling), feature hierarchy, and flattening for dense classification.
- `03-sequence-models-rnn/`: Recurrent hidden state transitions, text tokenization, vocabulary mapping, embedding lookup matrices, and handling sequential dependencies.

## Current Status

Scans and photos of my handwritten pages are being digitized and will be added progressively to their respective topic folders.
